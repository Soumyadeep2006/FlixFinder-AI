# 🍿 FlixFinder-AI

An AI-powered Movie Recommendation System built using Python, Streamlit, and Machine Learning.

## ✨ Features

- 🎬 Movie Recommendations
- 🖼️ Movie Posters (OMDb API)
- ⭐ Movie Ratings
- 📖 Movie Overview
- 🎭 Genre Information
- 🏆 Top Rated Movies Section

## 🛠️ Tech Stack

- Python
- Streamlit
- Pandas
- Scikit-Learn
- TF-IDF Vectorization
- OMDb API

## 🚀 Run Locally

```bash
git clone https://github.com/Soumyadeep2006/FlixFinder-AI.git
cd FlixFinder-AI
pip install -r requirements.txt
streamlit run app.py
```
